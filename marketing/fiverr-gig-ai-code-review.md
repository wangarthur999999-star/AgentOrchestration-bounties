## Gig Description

Get a professional, AI-powered code review that catches what humans miss.

My review checks your code across 4 dimensions:

**Security**: SQL injection, XSS, hardcoded secrets, unsafe crypto, path traversal, auth bypasses

**Bugs**: Null references, undefined variables, race conditions, edge cases, error handling gaps

**Performance**: N+1 queries, memory leaks, blocking operations, missing pagination, inefficient algorithms

**Maintainability**: Deep nesting, long functions, magic numbers, missing type hints, code duplication

You'll receive a structured report with:
- Issue severity (CRITICAL / HIGH / MEDIUM / LOW)
- Exact file and line number
- Clear description of each problem
- Actionable fix suggestions
- Summary statistics
