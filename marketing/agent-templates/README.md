# 10 AI Agent Templates for AutoGen & crewAI

Production-ready multi-agent system templates. Each is a complete, working project.

## Quick Start

```bash
pip install autogen crewai openai
export DEEPSEEK_API_KEY="sk-..."
cd template-name/
python main.py
```
